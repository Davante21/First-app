# Price Peek

A responsive higher-or-lower price guessing game. Guess whether an everyday item's typical retail price is higher or lower than the displayed price, build a streak, and try to beat your personal best.

## Run locally

No build step is required. Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Features

- Eight shuffled everyday products
- Persistent best score using browser local storage
- Keyboard controls (left/right arrows)
- Responsive mobile and desktop layout
- Accessible labels, focus states, and reduced-motion support

Product prices are illustrative U.S. retail averages and can vary by location.
